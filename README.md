# Progress

Круговой индикатор прогресса на HTML, CSS и JavaScript без сторонних библиотек и этапа сборки.

[Демонстрация](https://klixen5.github.io/progress-component/)

## Возможности

- Значение прогресса от 0 до 100.
- Вращение по часовой стрелке.
- Скрытие без сброса анимации и изменения расположения элементов.
- Переключение вертикальной и горизонтальной раскладки при смене ориентации окна.

## Запуск

Для локального запуска достаточно HTTP-сервера, например Live Server. Точка входа — `index.html`.

## Использование

Для подключения необходимы стили `progress/progress.css` и SVG-разметка из блока `.progress-indicator__progress` в `index.html`. Этот блок должен находиться внутри `.progress-indicator__container`, где объявлены CSS-переменные цветов. Элементы управления демонстрационной страницы необязательны.

В JavaScript-модуле:

```js
import progress from './progress/progress.js'

const circle = document.querySelector('.progress-indicator__circle')
progress(circle, 60, { animate: true, hide: false })
```

## API

`progress(circleElement, value, options)`

| Параметр | Описание | По умолчанию |
|---|---|---|
| `circleElement` | SVG-окружность дуги индикатора | Обязательный |
| `value` | Число или строка с числом | Обязательный |
| `options.animate` | Включение вращения | `false` |
| `options.hide` | Скрытие индикатора | `false` |

Значение преобразуется в целое и ограничивается диапазоном 0–100. Пустой и нечисловой ввод интерпретируются как 0. Каждый вызов обновляет значение и оба режима. Несколько индикаторов управляются независимо передачей соответствующей окружности.
